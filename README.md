# amos-tampermonkey-scripts

Tampermonkey scripts for Amos Exteriors (AccuLynx, GroupMe and Google Sheets helpers).

Each script has an update link built in. After you install a script from the link below, Tampermonkey checks this page by itself and offers the newest version whenever the `@version` number goes up.

## How to install a script (one time per script)

1. Click the **Install link** for the script in the table below.
2. Tampermonkey opens a page showing the code. Click **Install**.
3. Open the Tampermonkey **Dashboard**. If an older copy of the same script is listed, turn it off or delete it, so only one copy runs.

## How to get an update right away

Tampermonkey checks about once a day. To force it: click the Tampermonkey icon, then **Dashboard**, go to **Installed Userscripts**, and use **Check for userscript updates**. After a new version is saved here, give it about 5 minutes first.
